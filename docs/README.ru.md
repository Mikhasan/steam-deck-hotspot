# Раздача Wi-Fi на Steam Deck

Deck подключается к Wi-Fi и одновременно раздаёт интернет другим устройствам. Включение и выключение — одним ярлыком на рабочем столе.

[English](../README.md)

Проверено на **Steam Deck LCD, SteamOS 3.8.16**, адаптер RTL8822CE, драйвер `rtw88_8822ce`. Телефон получил интернет, включая подключение через VPN владельца. OLED и другие адаптеры не проверены.

## Установка

В **режиме рабочего стола** скачайте репозиторий через **Code → Download ZIP**, распакуйте, откройте Konsole в распакованной папке и выполните:

```bash
bash install.sh
```

Либо используйте Git:

```bash
git clone https://github.com/Mikhasan/steam-deck-hotspot.git
cd steam-deck-hotspot
bash install.sh
```

Появится ярлык **«Раздача Wi-Fi»**. Файлы устанавливаются в `~/.local/share/steam-deck-hotspot` (или в каталог `XDG_DATA_HOME`, если он задан). Пароль сети генерируется случайно; повторная установка сохраняет настройки.

Подключите Deck к Wi-Fi и запустите ярлык. Потребуется **системный пароль пользователя**, не пароль Steam. Если его ещё нет, задайте командой `passwd` в Konsole. KDE может попросить разрешить запуск ярлыка.

Первое включение установит недостающие `hostapd` и `dnsmasq` из репозиториев SteamOS. Для этого скрипт временно снимает защиту SteamOS от записи, а затем восстанавливает исходное состояние. Нужны работающий интернет и исправные репозитории/ключи пакетов. После обновления SteamOS пакеты могут исчезнуть — следующий запуск установит их повторно. Сам установщик запускайте без sudo.

## Использование

- Один запуск включает раздачу, следующий выключает.
- Имя сети, пароль и канал показываются в окне после запуска.
- Настройки: `~/.local/share/steam-deck-hotspot/settings.txt`. Первая строка — имя сети, вторая — пароль из 8–63 ASCII-символов. Изменения применяются после выключения и включения.
- После перезагрузки раздача автоматически не включается.
- При смене основной Wi-Fi сети или канала выключите и снова включите раздачу.

## Ограничения

Адаптер должен поддерживать одновременные режимы клиента и точки доступа. В выводе `iw list` смотрите `valid interface combinations`. Проверенный LCD поддерживает один `managed` и один `AP`, но только на одном канале (`#channels <= 1`).

Приём и раздача работают **на одном канале и в одном диапазоне**. Принимать на 2,4 ГГц и раздавать на 5 ГГц этим адаптером одновременно нельзя. Скрипт включает 802.11n с каналом 20 МГц, а не точку 802.11ac с полосой 80 МГц. Скорость может быть ниже прямого подключения: обе передачи используют одно радио.

Некоторые каналы, особенно DFS/ограниченные каналы 5 ГГц, могут не подходить для точки доступа. Скрипт не обходит региональные ограничения. При такой ошибке попробуйте разрешённый в вашем регионе канал роутера без DFS.

Раздача через VPN проверена в одной конфигурации; результат зависит от маршрутизации, firewall и kill switch конкретного VPN. Раздаётся IPv4, IPv6 на мосту выключен. Сон и пробуждение отдельно не проверялись.

## Устройство

`hostapd` управляет дополнительной точкой `deckhot0` с WPA2-PSK/CCMP. NetworkManager управляет мостом `deckbr0`, NAT, DHCP и DNS через `dnsmasq`. Основное подключение остаётся под управлением IWD: глобальные настройки Wi-Fi не переключаются, NetworkManager не перезапускается.

Для системных действий используется `pkexec`. Правила sudo без пароля и автозапуск при загрузке не добавляются. Временные настройки хранятся в `/run`, профиль `Deck-Hotspot-Bridge` сохраняется с отключённым автоподключением. Имена `deckhot0` и `deckbr0` зарезервированы для скрипта.

## Ошибки и удаление

Запуск с выводом в терминал:

```bash
bash ~/.local/share/steam-deck-hotspot/toggle.sh --terminal
```

Журнал: `~/.local/share/steam-deck-hotspot/last-run.log`. **После успешного запуска там есть пароль сети — удалите его перед публикацией журнала.** Настройки и журналы исключены из Git.

Дополнительная диагностика:

```bash
journalctl -b -u deck-hotspot-ap.service --no-pager
```

Если клиент подключился, но интернета нет, проверьте интернет на самом Deck и настройки VPN/firewall. Ошибки DNS репозитория или подписи пакета нужно устранить до повторного запуска. Проверку подписей скрипт не отключает.

Удаление:

```bash
bash ~/.local/share/steam-deck-hotspot/uninstall.sh
```

Будут остановлены раздача и её профиль, удалены временные настройки, установленные файлы, пароль, журнал и ярлык. Пакеты `hostapd` и `dnsmasq` останутся. Для другого пути установки скорректируйте команду.

Исходная версия проверена на LCD: включение, выключение, повторное включение, выдача адресов и интернет на телефоне. Установщик публичной версии проверяется отдельно автоматическими тестами; они не проверяют радиосвязь.
